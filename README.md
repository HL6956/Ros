# Ros
Remonterande rosor - 2favoriter
Med remonterande rosor menas att rosorna blommar flera gånger per säsong. Vi tipsar om fem av våra favoritsorter.

Astrid Lindgren ros
En underbart rikblommande och remonterande ros med stora klasar av rosa till laxrosa blommor. Doftar med en mild och söt doft som är mycket angenäm. Blomningen kan du njuta av hela sommaren och vidare fram till hösten.
